# 7 · API Specification

The API is REST over JSON, versioned under `/api/v1`, with 80 endpoints in 7 groups. Every endpoint maps to a service method in Section 10a and a screen in Section 8. The OpenAPI document generated by FastAPI is the machine-readable contract; the frontend generates its TypeScript client from it.

## 7.1 Conventions

| Topic | Rule |
| --- | --- |
| Auth | `Authorization: Bearer <access token>`; refresh via `HttpOnly` cookie on `/auth/refresh`. "Auth" column: **P** public, **U** user token required |
| Success envelope | `{ "data": <object or array>, "meta": { ... } }`; lists add `meta.next_cursor` and `meta.total` where cheap |
| Error envelope | `{ "error": { "code": "ACTIVITY_OVERLAP", "message": "...", "details": { }, "request_id": "..." } }` |
| Naming | snake_case JSON; plural nouns; actions as sub-resources (`/split`, `/merge`) only where a verb is unavoidable |
| IDs | UUID strings |
| Instants | ISO-8601 UTC with `Z` in responses; requests may carry an offset |
| Local dates | `YYYY-MM-DD`, interpreted in the entry's or user's timezone |
| Durations | whole minutes |
| Pagination | cursor: `?limit=20&cursor=...` (max 100); stable ordering stated per endpoint |
| Concurrency | mutable resources carry `version`; PATCH must send it; mismatch → 409 `VERSION_CONFLICT` |
| Idempotency | `Idempotency-Key: <uuid>` required on `process` and `review/commit`, accepted on other POSTs; replay returns the stored response; same key with a different body → 422 `IDEMPOTENCY_MISMATCH` |
| Caching | analytics return `ETag` (user `data_revision`); `If-None-Match` → 304 |
| Rate limits | Section FR-150; 429 with `Retry-After` |
| Tracing | request id from `X-Request-Id` or generated; echoed in responses and errors |
| Soft delete | deleted rows return 404; `restore` endpoints exist only where listed |

**Common errors.** 400 malformed JSON; 401 `UNAUTHENTICATED` or `TOKEN_EXPIRED`; 404 `NOT_FOUND` (also for other users' resources); 409 conflicts; 422 `VALIDATION_ERROR` with `details.fields = [{path, rule, message}]`; 429 `RATE_LIMITED`; 500 `INTERNAL`; 503 `UNAVAILABLE`. Endpoint-specific codes are listed below.
